`standard-grid.json` (860 nodes, 881 links, 98 clusters, with x/y layout) and `standard-routes.json` (per-character start nodes and baseline routes) are derived from Grayfox96's **FFX Sphere Grid viewer** (https://github.com/Grayfox96/FFX-Sphere-Grid-viewer), MIT License, Copyright (c) 2024 Grayfox96.
