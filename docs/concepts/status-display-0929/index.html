Status Display Options

“Kimahri probably had the zombie status effect but even if so the status effects in general not noticeable or obvious like in the actual ffx/ffx-2 games. I like how status effects are displayed in the games. That should be examples.”

Three ways to show statuses, each drawn over our own battle frames for both games at 1600×900 and on a 390×844 phone. Nothing is built yet. Pick one, or mix them per game. Every option includes the one before it. All icons and effects are new drawings. The looks they copy come from sourced descriptions of the originals, never from retail art.

Red rim: hurts the unit that has it Teal rim: helps the unit that has it

Option 1As the originals

What it is
Statuses live on the figure, the way each game draws them: Zombie's green glow and black smoke, Poison's green bubbles, Sleep's Z's, FFX-2's Silence speech bubble and darkened Curse. FFX-2's top help line lists the targeted unit's icons. The HP windows show no standing icons, as in both originals.
Faithful
As close as the sources allow. A look the sources do not describe gets nothing, such as FFX Slow, Shell and Reflect. O1 also drops today's FFX-2 text chips.
Cost
The largest piece: a new on-figure status layer for both games. The Sleep hunch and the low-HP slouch would need new paintings.

Option 2Originals + at a glance

What it is
O1, plus a crisp icon row on every HP plate and for every enemy. FFX gets round medallions under the Overdrive gauge and beside turn-list names. FFX-2 gets square tags where today's chips sit, plus a STATUS tab on the boss bar with Doom's count.
Faithful
FFX never showed standing icons, so for FFX this is an addition. FFX-2 has an icon for every status, and this shows them in one more place.
Cost
O1, plus about 20 small glyphs and the plate, turn-list and boss rows. HUD work only; the FFX-2 chip code is replaced.
Agents’ pick

Option 3Originals + guard rails

What it is
O2, plus a warning when a status changes what an action does. Aiming a Hi-Potion at a Zombie shows “−1000 KO” in red, a ZOMBIE tag and a guide note on the cure. A one-line message appears when a status lands or wears off.
Faithful
Not in either original. Every rule a warning states is sourced, and a status with no sourced rule gets no warning.
Cost
O2, plus a forecast that reads the engine. It builds on the Hi-Potion fix branch once that lands.
