# Chateau Leblanc — the Last Room (FFX-2, Ch.2) — end-state options

**Nothing here is built or wired into the game.** Hard-rule-9 concept art for the
approved Leblanc Syndicate chapter (the three-act "Faking and Entering" mission,
Act III). Pick or mix per row; a pick approves only the properties named, not the
whole image (AGENTS.md rule 15).

`sheet.png` — four rows, options A/B/C left to right. `options.json` has the full
canon notes and everything off-canon spotted while judging.

## Questions for Bailey, one per row

1. **Backdrop** — which palette for the basement treasure room: A (cool cyan,
   reads sci-fi), B (warm amber, reads lived-in but not very Guado), or C (mixed
   magenta/cyan with a heart-motif door — closest single match to the brief)?
2. **Boss — Leblanc** — A (fan as a screen), B (fan open, stage address), or C (fan
   snapped shut, smirk)? None of the three carry her specific blue-and-white
   triangle/swirl robe pattern — flagged for a follow-up pass on whichever is picked.
3. **Cast — Ormi** — only **A** is recommended; B and C came back off-canon (slim
   swordsman builds, wrong weapons) despite the "short stout, shield only" tags, and
   were not re-rolled a second time (one-reroll-per-item cap). If none of A/B/C
   satisfy, the honest answer is that Ormi needs a second full attempt, not a pick
   among these three.
4. **Cast — Logos** — **A** and **C** are on-canon (revolver visible); **B** is a
   clear miss (he's holding a box, not a gun). Recommend picking between A and C.

## What went off-canon during rendering

- **Ormi's first roll** (pre-reroll A) came back as a tall slim swordsman with a
  long curved blade — no shield at all. Re-rolled once under tags forced toward
  "shield, no weapon in hand" — that reroll is the current option A and is on-canon.
  Options B and C (separate seeds, not the same reroll budget) also drifted to
  slim-swordsman builds and were kept, flagged, not re-rolled again.
- **Logos's first roll** (pre-reroll A) came back as a katana-wielding samurai with
  an antlered helmet — no revolver. Re-rolled once toward "revolvers, no
  sword/horns" — that reroll is the current option A. Option B (separate seed) is
  holding a box instead of a gun and is flagged as a miss; option C is the cleanest
  revolver read of the whole set.
- Backdrop and Leblanc-boss renders are all usable; deviations are cosmetic
  (missing pattern/motif details) rather than disqualifying — see `options.json`.
