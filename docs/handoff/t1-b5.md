## Method note (rule 15)

None of this batch's items is on round 13's stalled list, but PR-0195 was in its 5th
review. Why it kept failing: every attempt waited for someone to export a real
previous-release save by hand, and nobody did, so the matrix was never run. What
changed: the fixture is now generated from the live previous release itself (its own
SaveStore methods on a fresh profile, then localStorage read back), which takes a minute,
and the spec injects it before boot. Refresh the fixture the same way at each
persistence change.
