## 1. What this branch does

1. **Chapter XI plays grade C by default.** `look/pro/SkyGrade.ts` gains `SKY_DEFAULTS = { 'ffx2-fallen-aeons': 'c' }` and `skyGradeFor(id)` answers the chapter's default when the address says nothing. Chapter XI's `hd2d` and `arena` holds left `PIECE_HOLDS`, so the HD-2D bold look and the pro arena grade play on the Road, with option C (the dimmer bold row: exposure capped at 1.2, the beams 2.0 to 0.8, the stage light 1.7 to 1.2, the bloom 0.85 to 0.45 at a threshold of 0.66 to 0.8, the figure key 1.5 to 1.3, the cone at 0.7 of itself) patched on the room's pro table by `skyRoom`. The shipped rows of `ProGrade.PRO_ARENA` are never written (a test reads them back).
2. **`?skygrade=today` restores release 71's Chapter XI exactly.** The two holds moved to a new data file, `src/engine/motion/PieceHoldsSky.ts` (`SKY_TODAY_HOLDS`, the r71 reasons rewritten around the word), and `DemoGate.treatedHold` answers them only while the address says `today`. So every reader of `isTreatedChapter(id, piece)` sees the same two holds as in release 71: no look rig, no arena, no grade, the plate as release 69 draws it, and `treated().holds` lists the same five pieces in the same order. `__pyrefly.skyGrade('today')` sets it live (a battle already running keeps its rig: open the page with the word to film release 71's frame).
3. **The measuring word keeps `a`, `b`, `c`.** In either chapter a named option wins over the default (`?skygrade=a` in Chapter XI plays option a, in Chapter V plays the held look with option a, as in release 71's branch). `__pyrefly.skyGrade(null)` is still the control arm: NO grade at all, even in Chapter XI where the default would be C, so the room's own table plays unpatched (`screen` `r70`).
4. **Chapter V keeps today's sky.** C leaves 3.97 and 4.14 percent of the whole frame and 20.9 and 21.9 percent of the sky band over 240 in Chapter V's link 1 stills (the lift's number is under 3 on the sky band), so V has no default row: both holds stand and only a named option plays the look there.
5. `__pyrefly.skyGrade()` also returns `mode` (the whole word: `a` | `b` | `c` | `today` | `off` | `default`) and `defaults`; `__pyrefly.treated().holds` reads `DemoGate.treatedHolds`, which includes the pieces `today` adds.
6. The word's state moved from `SkyGrade.ts` into `DemoGate.ts` (`skyWord`, `setSkyWord`, `skyWordFromSearch`, `SkyWord`), beside `?treated=`: the hold lookup must read it and `SkyGrade.ts` imports the gate, so the state could not stay in `SkyGrade.ts` without an import cycle. `SkyGrade.ts`'s own exports (`skyOption`, `setSkyOption`, `skyOptionFromSearch`, `skyGradeFor`, `skyActive`, `skyRevision`, `skyRoom`, `skyScreen`) keep their meaning; `setSkyOption` also takes `'today'`, and `null` is the forced "no grade".
