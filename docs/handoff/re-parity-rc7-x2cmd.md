## 2. How it is built

- **Kernel** (`src/battle/ffx2/kernel/`, pure, no draw): `command-menu-rows.ts` is the 554 command rows' menu fields as numbers (`flags`, `group`, `child`, `key`, `order`, `ap`, `cursor`, `misc`, `mp`; read from `command.bin`, no text); `command-menu.ts` ports the party command list, the builder (first pass with the learned-child expansion, second pass with the 0xff quirk), the list writer and the stable sort; `command-usable.ts` ports the usability test and exports `silenceable`. They sit on the dressphere lane's proven pair tables, prerequisite test and ability rows (`dressphere-*.ts`), which were unwired before this.
- **Adapter** (`adapt/menu.ts`, `adapt/game-ids.ts`): our ability and dressphere ids against the game's numbers (217 ids: 200 matched by name inside each dressphere's own pairs and 17 for the abilities this lane adds or the ladders now name; the Trainer's pet moves read from each girl's own ladder), and `offeredAbilityIds`, `isSilenceable`, `menuCategoryOf`, `autoWordsOf`. Two limits, both deliberate: the engine models no key items, gate slots, garment-grid command pairs or accessory pairs, so the kernel is given none (the kernel's plate and accessory paths are proven by its own vectors); and **the build's learned list stays the authority** on what she has learned: the kernel adds only what the game lists without learning (the free pairs), never a command the build did not give her, and takes the prerequisites of a learned move as learned (a build cannot say which AP she holds; Chateau's Yuna has Cheap Shot without Potshot and keeps her menu).
- **Engine** (`menu.ts`, new; `targeting.ts` was at 397 of 400 lines and is now 123): `buildCommands`, `effectiveMpCost`, `hpCostFor`, `berserkCommand` moved; `resolve.ts` pays `effectiveMpCost`; `setup.ts` and `spherechange.ts` keep `Ffx2Unit.autoWords` (`internal.ts`, engine-internal: not a contract file, no `docs/CONTRACT-CHANGES.md` entry). `GateBonus.autoTags` (`adapters.ts`, `garment-grids.ts#gateAutoTags`) carry the grid's Half MP Cost, One MP Cost and Magic Booster tags.
- **Data**: `DressphereAbilityEntry` gains `free`, `prereqAll` and `keyItem` (all optional, data-internal); the ladders follow the game's pairs; nine dresspheres' ladders now add up to the published mastery totals (Gunner, Warrior, White Mage and Black Mage as before; **Thief, Songstress, Dark Knight, Samurai and Alchemist** newly: each gap was exactly the missing entries).

## 8. What the grouped command window would need (the release driver's, after a mockup; nothing here is on screen)

- **The data source exists**: `menuLists(world, record)` returns the main list, the shortcut list (kind 0x16: Escape, the only row there) and the group lists (Black Magic 14, White Magic 16, Swordplay 12, Bushido 12, Arcana 12, Instinct 8, Blue Bullet 16, and groups 0xb to 0xd of 8 or 10 by dressphere) already in the game's order (the `+0x7e` key, stable). The adapter would pass it the same world it passes `buildMenuTable`.
- **What a row would have to carry** (additive on `AvailableCommand`, a contract entry in `docs/CONTRACT-CHANGES.md` then): the parent heading it files under (a game command id, one of the 41 named parents of the note's table 3.2, or none), its order key, and whether the heading is shown (a 0x10 parent only with an available child; a 0x08 parent such as Item, Dresspheres, Blue Bullet and Mix always once listed). The headings have no ability of ours; they would be labels.
- **The pages**: the root list does **not** stop time, every other page does (sub-list, shortcut list, gil amount page, Lady Luck's reels page, target cursor): the engine's Wait reading B holds sub-lists and aiming but not the shortcut, amount and reels pages (E9). Pushing, popping and the banner rule are in the note's 2.6.
- **Greyed vs hidden**: Itch greys every row; a Cursed girl's dress ids are blocked; a 0x20 parent (greyed instead of hidden when childless) exists in the code but no row uses it.
- **The Dresspheres row**: in the game it is a main-list row (0x3002) opening the dress list; the engine has the L1 spherechange rows (the Garment Grid shortcut). The save word's bit 2 (Dresspheres) is 0 in a new game (`ply_save` value 3: Item and Escape); who sets it is open (note, open question 4).
- **Target pages**: the cursor flags (target type, side first, reverse, can target the dead, far 0x400), the Scan III reverse flag, the team-split draw on stream 5 (note 2.8) are proven in the note and not ported here.
- **The menu memory** (12 slots, saved at submit, cleared when her dressphere differs) and the HUD can-select wrapper (a heading is selectable when its list is non-empty) are read-only in the note.
- A mockup first (rule 9): a Gunner's mastered menu is Attack, Trigger Happy, Gunplay, Item, Dresspheres with Escape on the shortcut; the main lists at mastery are in the fixture `command_menu.json` for all 34 dresspheres on all three girls.

## 11. Player-facing paragraph for CHANGELOG.md (FFX-2 only)

**FFX-2 only.** The battle menu now follows the game's own rules for what a girl can use. The commands a dressphere gives you from the start are there before you learn anything (Pray, Cure, Power Break, Fire, Blizzard, Thunder and Water), the passive abilities you learn (Darkproof, Trigger Happy Lv. 2, Counterattack and the like) no longer appear as commands you can pick, and Yuna, Rikku and Paine each have their own Trainer moves. While a girl is Itchy every command stays on the list but greyed out, with Escape and changing dressphere the ways out. Silence now stops everything the game stops, every Dance and Song and the Dark Knight's spells included, and leaves Pray, Vigor, Focus and MP Absorb alone. Moves that cost MP follow Half MP Cost, One MP Cost and Magic Booster the way the game does, and a girl in a Special dressphere has no Item or Escape command. The Samurai gains Magicide, Dismissal, Fingersnap, Momentum, Shin-Zantetsu and Clean Slate, the Alchemist gains Dispel Tonic and Mega Phoenix, and the order in which commands unlock now matches the game for the Samurai, Thief, Berserker, Warrior, White Mage and Alchemist.
